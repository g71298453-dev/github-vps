Help & Common Questions

Learn about fields, features, and troubleshooting on your Nahan Gateway.

ENEnglish

Nahan Gateway is an advanced, high-performance, single-file subscription and proxy manager built directly for Cloudflare Workers. It acts as a gateway to securely distribute configurations (Clash, Sing-box, Trojan, VMess) to clients while concealing the main panel's backend server behind Cloudflare's global edge network.

ZH中文

隐藏网关是一个订阅和代理管理系统，是专为Cloudflare Workers开发的单文件。这个系统作为网关运行以使配置（Clash, Sing-box, Trojan, VMess）安全分发并将您的服务器隐藏在Cloudflare全局网络之后。

ENEnglish

When Auto-Update is enabled in System settings, a Cron Trigger runs on the background periodically checking the GitHub repository for updates. If a newer version is released, the worker automatically pulls the fresh code, applies the selected format (Normal or Obfuscated), deploys itself directly, and triggers updates across all linked panels/nodes.

ZH中文

当自动更新在 设置 活跃 启用时，定时任务会在后台定期检查GitHub仓库版本. 如果有新版本，Worker会自动获取新代码，选择的格式 (普通 或混淆的) 应用后，直接部署并 节点/同步已连接的面板.

ENEnglish

Normal: Deploys raw JS code. Easily readable, but prone to traffic analysis/firewall scanning.
Obfuscated: Uses XOR byte-shifting to obscure the source code. The Cloudflare Edge compiles it at runtime using high-speed dynamic decoders, preventing third-party scanning.

ZH中文

普通: 部署原始JavaScript代码。易读但暴露于防火墙流量分析。
混淆: 使用XOR字节移位进行代码混淆。Cloudflare在运行时快速解密它。

ENEnglish

The Clients tab lets you provision individual subscriber tokens with specific limits (Quota, Expiry, IP connection count limits). Subscription Fake Entries customize what gets shown in the subscription profile UI inside the client app, such as remaining traffic or days left using placeholder patterns like {usage} and {expiry}.

ZH中文

标签 用户 允许您为每个订阅者设置流量限制、到期日期和并发连接数。订阅条目输入 确定哪些消息使用动态代码如 {usage} 和 {expiry} 在用户软件中显示。

ENEnglish

"Other Nodes" represents external linked panels. By generating a Panel API Key and registering the child node's URL, the main panel automatically synchronizes, updates, and deploys the identical worker code to all linked nodes whenever an update is triggered on the main panel.

ZH中文

«其他节点» 已连接的从面板. 通过创建面板访问密钥 (API Key) 和注册 节点地址 从面板，主面板每次更新时自动将新版本发送给所有 节点已连接的面板并发送部署.

ENEnglish

Clean IPs: Clean non-filtered Cloudflare IPs. The gateway generates unique config sets multiplied for each clean IP added here, giving users redundancy.
Proxy IPs: Behind-the-scene IPv4/IPv6 transit nodes to fetch data from blocking target sites.

ZH中文

干净IP: 未过滤的Cloudflare IP. 这个 系统 为该部分中注册的每个IP生成单独的输出以提供稳定连接.
代理IP: 后台传输IP用于与被过滤的目标网站通信.
